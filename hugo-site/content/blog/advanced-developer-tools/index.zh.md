大多数「免费在线工具」止步于基础：格式化一段 JSON、生成一个 UUID，完事。真正能救下专业人士一个下午的，是那些做*结构性*工作的工具——签发 token、重排查询、画图、切分网络。这类工具之所以很少以免费、本地、免注册的形式出现，是因为它们确实更难做。

这 6 款补上了这个缺口。每款都 100% 在浏览器内运行，使用浏览器自带的密码学和引擎，做的是简单工具做不了的活。它们与 [17 款工具总览](/zh/blog/free-developer-tools/)同属 AI Forward 工具中心——这一批是实力档。

## 1. JWT 签发工具：不止会读，还会造

解码 JWT 很容易；签发需要真正的 HMAC 原语。[JWT 签发工具](/zh/tools/jwt-signer/)用 Web Crypto API——生产库调用的同一个 `crypto.subtle.sign`——计算 HS256 签名，用你自己的 header、payload 和密钥生成真实的 `header.payload.signature` token。密钥不离开标签页，与 [JWT 解码器](/zh/tools/jwt-decoder/)配对形成闭环：解码为理解，签发为构建。它负责签发，刻意不假装能验证。

## 2. SQL 格式化器：驯服单行怪

ORM 日志把 SQL 吐成 400 字符的一行，没人能调试那个。[SQL 格式化器](/zh/tools/sql-formatter/)对查询做词法分析——原样保留字符串、注释和带引号的标识符——再按结构重建：关键字大写、每个主要子句独立成行、`AND`/`OR` 单独拆出、括号缩进。它是格式化器，不是校验器：方言怪癖原样通过，你的 diff 工具终于显示真正的改动而不是空白噪音。

## 3. 正则可视化器：看得见的模式

40 个字符的正则是一门语言；它的铁路图是 5 秒的扫视。[正则可视化器](/zh/tools/regex-visualizer/)解析正则的实用子集——字面量、`\d \w \s .`、字符类、分组、分支、量词、锚点——并把语法树画成 SVG 图：原子是盒子、分组是容器、分支是岔路、量词是标签。它服务于读别人的正则、教学和会传播的截图。测试仍然是[正则测试器](/zh/tools/regex-tester/)的活。

## 4. CIDR 子网计算器：不用表格的网络规划

子网算术是没人该重做第二次的 10 分钟表格作业。[CIDR 计算器](/zh/tools/cidr-calculator/)输入 `192.168.1.0/24`，返回一切——网络、广播、首末主机、可用数量、子网与通配符掩码、地址类别——外加现成的八个更小子网拆分表，全部用 BigInt 精确位运算（/0 到 /32 及 /31、/32 边界情况都正确）。网络规划和 VPC 设计省下的时间，正好是你过去用来重算的时间。

## 5. Markdown 预览器：边写边看，无需构建

文档草稿不该为了读一眼就跑一次构建。[Markdown 预览器](/zh/tools/markdown-previewer/)随输入实时渲染——标题、强调、行内与围栏代码、链接、图片、列表、引用——HTML 先转义，粘贴的标记保持惰性。它刻意瞄准日常的 90%；表格和脚注属于完整渲染器。LLM 提示词作者会发现第二个用途：结构化 Markdown 提示词读起来完全符合预期。

## 6. Prompt 对比测试器：可测量的提示词工程

提示词质量在实验跑起来之前只是说法。[Prompt 对比测试器](/zh/tools/prompt-compare/)把两个提示词并排发到任意 OpenAI 兼容 API，报告两边的输出、token 用量和延迟。请求从浏览器直连 API 服务商——本站没有后端，永远看不到你的 key 和提示词（key 仅为方便存进 `localStorage`，共用电脑请删除）。对比措辞、输出格式，甚至两个模型——再用 [Token 费用计算器](/zh/tools/ai-token-cost-calculator/)给两边标价。

## 共同点

六款工具共享最初 17 款的可信属性：**本地执行**（数据不离开本机）、**浏览器受审计的引擎**（Web Crypto、原生解析器）、**零账号**（静态页面、无配额页、没有会坏的东西）。区别在于每款所做工作的深度——以前需要库、脚本或表格才能完成的结构性工作。这就是工具中心的全部论点：**浏览器是你已经拥有的、最未被充分利用的开发环境。**
