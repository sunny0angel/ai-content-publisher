大多数「免费媒体工具」价格免费、隐私昂贵：为了压缩，你的照片被传到陌生人的服务器上。日常文件尚可容忍；含客户数据的截图、医疗文档、私人录音则不能。本总览的 18 款工具拒绝这笔交易——每一款都通过 canvas、Web Audio 和 MediaRecorder API **完全在浏览器内**处理文件。永不上传。

## 图片工具（10 款）

**1. [图片压缩器](/zh/tools/image-compressor/)。** 设置 JPEG 质量与最大宽度，原图与压缩版并排对比，节省体积如实计算。质量 70–80 几乎无视觉损失，体积却小得多。

**2. [图片格式转换](/zh/tools/image-converter/)。** JPG、PNG、WebP 一键互转。截图与透明用 PNG，照片用 JPG，体积质量比最佳用 WebP。

**3. [图片尺寸调整](/zh/tools/image-resizer/)。** 目标宽、高或百分比。填一个维度，另一个等比缩放。

**4. [图片裁剪器](/zh/tools/image-cropper/)。** 预设宽高比——头像 1:1、幻灯片 4:3、封面 16:9——带中心位置与裁剪大小滑杆。

**5. [图片旋转与翻转](/zh/tools/image-rotator/)。** 修正横拍照片：左右 90° 旋转、水平垂直翻转。

**6. [图片滤镜与调节](/zh/tools/image-filter/)。** 灰度、复古、反色、模糊，以及合成进一次渲染的亮度与对比度。

**7. [图片取色器](/zh/tools/image-color-picker/)。** 点击任意像素复制 HEX 值，并自动提取六大主色调——品牌调色板不再头疼。

**8. [图片像素化](/zh/tools/image-pixelator/)。** 可调块大小的马赛克，分享前隐藏人脸、车牌和敏感文字。

**9. [图片水印工具](/zh/tools/image-watermark/)。** 可调位置与透明度的文字水印——任何背景上都可读。

**10. [图片转 Base64](/zh/tools/image-to-base64/)。** 直接嵌入 HTML `src` 和 CSS 的 Data URL——无需单独文件、无需请求。

## 为什么媒体文件更需要本地处理

媒体文件是多数人手里最敏感的文件：截图里有对话和账户信息，录音里有声音，照片带位置元数据。「免费」的服务端工具把这一切放在别人的磁盘上处理，受别人的留存政策支配。浏览器方案把模型反过来：

- **文件不动。** canvas 和 MediaRecorder API 作用于浏览器内存里已有的数据
- **不上传就没有上传风险。** 工具提供商再被攻破，也泄露不了它从未收到的文件
- **成本随规模归零。** 静态页面不需要后端、存储或基础设施预算——这正是这些工具能永远免费、没有配额页、没有「登录后继续」的原因

代价也要说清：浏览器工具是单文件、单功能的。批量处理、专业调色和团队工作流属于桌面软件。对日常的单个文件——要压缩的截图、要裁剪的照片、要截取的录音——浏览器比启动一个应用更快。
