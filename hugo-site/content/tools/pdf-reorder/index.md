## How it works

Pages are copied into a new document in the exact sequence you enter; any page you leave out is dropped, and pages can be repeated. To reverse everything at once, use [reverse page order](/tools/pdf-reverse-pages/); to add copies, use [duplicate pages](/tools/pdf-duplicate-pages/).

## Good to know

- List every page you want to keep — omissions are deletions
- Repeat a number to duplicate that page in place
- Check the page count first with the [PDF inspector](/tools/pdf-info/)
