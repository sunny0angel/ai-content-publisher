## 仕組み

両方の文書をパースし、再帰的に走査してオブジェクトをキーごと、配列を要素ごとに比較します。変更値は `パス: 旧 → 新` の遷移で表示され、新規と削除は緑と赤でマークされます。JSONでなくテキスト文書なら[テキスト差分チェッカー](/ja/tools/text-diff/)が適任。比較前に両側の検証を[JSONフォーマッター](/ja/tools/json-formatter/)で。
