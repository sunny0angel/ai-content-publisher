Repeat the whole document two, five, or twenty times inside a single PDF — handy for print runs, handout packs, and ticket sheets.

## How it works

Every page is copied N times in sequence, producing one file with N complete copies. For inserting a single page twice, use [reorder pages](/tools/pdf-reorder/) and repeat that page number. The [blank page generator](/tools/pdf-blank-pages/) handles separators.

## Good to know

- Set N to the number of copies you actually need to print
- Copies are appended whole, not interleaved
- Combine with N-up to save paper: [PDF N-up](/tools/pdf-n-up/)
