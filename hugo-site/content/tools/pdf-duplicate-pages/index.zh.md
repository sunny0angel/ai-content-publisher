在一份 PDF 里把整个文档重复两次、五次或二十次——适合打印份数、讲义包和票据页。

<!--more-->

{{< pdf-duplicate-pages >}}

## 工作原理

所有页面按顺序复制 N 次，生成含 N 份完整副本的文件。只想把某一页放两次，用[页面重排](/zh/tools/pdf-reorder/)重复该编号；分隔页用[空白 PDF 生成器](/zh/tools/pdf-blank-pages/)。

## 使用提示

- N 设成你实际要打印的份数
- 副本是整体追加，不会逐页交替
- 配合 N-up 省纸：[PDF N-up](/zh/tools/pdf-n-up/)
